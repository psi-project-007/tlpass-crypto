# tlpass-crypto v1 test vectors

These files are the v1 format contract. Every client must pass all of them.
**Changing, removing or reordering any vector is a breaking change and needs a new major version.** Adding vectors is not.

Generated by the scripts in `scripts/` with Python (`cryptography`, `hashlib`), independent of this library.

| File | Function(s) | Inputs | Expected output | Script |
|---|---|---|---|---|
| `master-key.json` | `deriveMasterKey`, `normalizedEmail` | email, password | 32-byte key (hex) | `master-key-vectors.py` |
| `split-keys.json` | `splitKeys` | master key | Auth Hash, vault check | `split-keys-vectors.py` |
| `vault-key.json` | `wrapVaultKey`, `unwrapVaultKey` | Vault Key, wrapping key, nonce | `v1.<nonce>.<ct>` | `vault-key-vectors.py` |
| `vault-key-rewrap.json` | `rewrapVaultKey` | Vault Key, old and new wrapping keys, new nonce, old slot | new slot `v1.<nonce>.<ct>` | `vault-key-rewrap-vectors.py` |
| `entry.json` | `encryptEntry`, `decryptEntry` | Vault Key, user id, item id, nonce, entry | `v1.<nonce>.<ct>` | `entry_vectors.py` |
| `bip39.json` | `generateRecoveryWords` | entropy | mnemonic | official BIP-39 vectors |
| `recovery.json` | `deriveRecoveryKeys` | phrase | verifier, slot check | `recovery-vectors.py` |
| `pwned.json` | `isPwned` | password | SHA-1 prefix, suffix | `pwned-vectors.py` |
| `password.json` | `generatePassword`, `checkMasterPassword`, `strengthScore`, `charsetSize` | options + random stream, password | password, failing rules, score, size | `password-vectors.py` |

`createVaultKey` has no vector: it is random and non-extractable. It is covered by the round-trip tests and the wrap/unwrap vectors.
